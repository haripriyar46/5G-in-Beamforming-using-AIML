In 5G, everything is software controlled. We don’t use big hardware machines like in old networks. This makes the network more flexible and smarter.

Now, when a user wants to use the internet or make a call, the system needs to send signals to their phone. But instead of sending signals in all directions, we find out where the user is and send the signal only in that direction. This is called beamforming – like focusing a flashlight instead of lighting up the whole room.

To do this smartly, we use a technique called ray tracing. It helps us understand how signals travel through the environment – some signals come straight to the user, and some bounce off buildings or walls.

In our project, we keep it simple and only consider two signals:

1. One that comes directly to the user (line of sight).

2. One that comes after bouncing off something (reflected ray).

We then make a model based on these two signals to understand how they combine and reach the user’s phone. This helps improve the quality of the signal and makes communication faster and clearer.

How We Generated the Data:

We used a software tool called RCOM to simulate how 5G signals behave in a real-world setup.

To make it realistic, we made a few assumptions:

1.Urban Outdoor Terrain

This randomness helps us test the system in different real-time situations and see how the signal behaves when phones are tilted or rotated.

How We Send the Signal to the User:

To send data to the user’s phone (User Equipment or UE), I need to know two main things:

1. Where the user is (UE position)  
2. What the environment is like – Are there buildings? Are there chances of signal reflection? How much signal gets lost?

Understanding the Environment:
When we send a signal:
- Some of it reaches the user directly.
- Some of it bounces off buildings (reflected).
- Due to this, the signal may become weaker or change its timing and phase.

This affects the quality of what the user receives. So we must be smart and send the signal in a way that overcomes these problems.

Step 1: Sending a Pilot Signal
When we are starting for the first time, the system (RNC) sends a pilot signal – which is just a test signal.

This helps us measure:
- How much signal is getting lost (path loss)
- How the signal is changing in the environment (reflections, delays, phase shift)

Step 2: Calculating Beamforming Weights
Once we get the results from the pilot signal, we analyze that data.

From that, we calculate beamforming weights – this is like figuring out the best angle and strength to send the next signal so that the user gets it clearly.

Step 3: Sending the Actual Signal
Now, using these weights, we send the actual data signal.

This second signal is now adjusted perfectly for that user's location and environment, so the user gets a strong and clear connection.

Summary:
- First, we test the environment with a pilot signal.
- Then, we learn how to adjust our beam.
- Finally, we send the real data with optimized direction and strength.

This is the process we use to set up beamforming and make sure the signal reaches the user in the best possible way.


Why We Calculate Beamforming Weights
Beamforming weights help us decide how much signal to send from each antenna element and in which direction, so that all signals combine perfectly at the user’s location.

To calculate these weights, we first need information like:
-User location
-Path loss
-Channel conditions (how the signal behaves in the environment)

This information is obtained through the pilot signal we send at the beginning.

What Do We Get from Beamforming Techniques?
Based on the beamforming technique we choose, we get:
- A set of weights (one for each antenna element)
- A signal that is strong, has less interference, and is optimized for the user

Now let's look at the three techniques, in very simple terms:

Maximum Ratio Combining (MRC) – Focus on Signal Strength

- It gives maximum power to the direction where the user is.
- All antennas are tuned to send signals that add up at the user with maximum strength.
- Very simple and good for low interference situations.

Good for: Maximizing signal power  
Not great at: Handling interference from others

Zero-Forcing (ZF) – Focus on Eliminating Interference

- Tries to completely cancel out interference from other users.
- Adjusts the beamforming weights in such a way that interference becomes zero.
- But sometimes it also reduces the main signal power.

Good for: Multi-user setups with high interference  
Not great at: Weak signal conditions

Minimum Mean Square Error (MMSE) – Balance Between Power and Interference

- A smarter approach that balances both:
  - Keeps signal strength as high as possible
  - Reduces interference as much as possible
- It finds the optimal trade-off between MRC and ZF

Good for: Real-world conditions (signal + interference mix)  
Often preferred in practice

Our Idea Behind Beamforming Weight Calculation

Each beamforming technique (like MRC, ZF, MMSE) comes with its own advantages and drawbacks especially when it comes to noise.

In some techniques, when we apply very large weights, not only the signal but even the noise gets amplified. This can make the received signal unclear or weak.

Why We Use MRC (Maximum Ratio Combining)

To handle this problem, we use MRC – Maximum Ratio Combining.  
(Sometimes mistakenly called *minimum* ratio, but it's actually *maximum* ratio of signal to noise.)

- MRC **focuses on maximizing the useful signal**.
- It gives more weight to the **stronger and cleaner signals**, while naturally reducing the effect of noise.
- This helps in creating a **more reliable and strong beam**, especially when the number of users or antennas increases (like in massive MIMO).

So, in our project, we are using this MRC method to calculate the beamforming weights.

How We Use These Weights

Once we have the weights:
1. We feed them into the antenna system.
2. The antenna system uses these weights to form a directional beam.
3. This beam focuses the signal exactly towards the user's location.
